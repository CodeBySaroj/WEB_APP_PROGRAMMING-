# Saroj Yadav — Portfolio Website

A professional, modern portfolio website with a deep navy + electric teal color palette.

## Project Structure

```
saroj-portfolio/
├── index.html        # Main HTML file
├── css/
│   └── style.css     # All styles (no frameworks)
├── js/
│   └── main.js       # All interactivity
└── README.md
```

## Tech Stack
- Pure HTML5, CSS3, JavaScript (no frameworks)
- Google Fonts: Syne + DM Sans + DM Mono
- Responsive via CSS Media Queries

## Features
- Custom animated cursor (desktop)
- Typewriter hero effect
- Scroll-triggered reveal animations
- Animated skill progress bars
- Mobile hamburger drawer
- Contact form with feedback
- Smooth scrolling
- Active nav highlight on scroll

## Customization
- Update contact links in `index.html` (GitHub, Email, LinkedIn)
- Edit personal info, projects, skills as needed
- Color variables are in `css/style.css` under `:root`

## Deployment
Drop the folder into any static host:
- GitHub Pages
- Netlify (drag & drop)
- Vercel
